description: При любом изменении обязательно проверять все связанные места — контроллер, модель, валидацию, миграции, шаблоны
type: feedback
---
При внесении изменений обязательно проверять все связанные участки кода: вызывающие, потребляющие, валидирующие.
Для формы: контроллер -> валидация -> модель (мутаторы, касты) -> миграция (NOT NULL, defaults) -> blade-шаблон.
**Why:** при снятии required с полей экскурсий пропустили NOT NULL в БД и строгую типизацию мутатора модели — получили два последовательных бага.
**How to apply:** перед каждой правкой составить цепочку зависимостей и проверить каждое звено. Особенно: типы аргументов в мутаторах, nullable/NOT NULL в миграциях, default-значения.
