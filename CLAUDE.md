# Museum — Иркутское юнкерское училище

Сайт музея «Иркутское юнкерское училище», г. Иркутск. Laravel 11, Blade, vanilla CSS/JS.

## Память проекта
Вся память и документация по проекту хранится только в `.claude/memory/` внутри этой директории.
Индекс: `.claude/memory/MEMORY.md`. Глобальная директория Claude не используется для хранения памяти этого проекта.

## Конвенции
- Язык общения и комментариев: русский
- CSS: BEM, vanilla CSS (`public/css/`)
- JS: vanilla JS (`public/js/`)
- Blade-шаблоны: kebab-case в `pages/`
- Роуты: kebab-case, именованные
- Рабочая директория Laravel: `server/`
- Сборка (Vite) не используется — assets из `public/` через `asset()`
