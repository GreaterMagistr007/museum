# Музей «Иркутское юнкерское училище»

Информационный сайт музея «Иркутское юнкерское училище» (внештатное музейное образование, г. Иркутск).

Здание бывшего юнкерского училища расположено по адресу: ул. 5-й Армии, 65 / ул. Ярослава Гашека, 5.

Три исторических периода:
- Иркутское юнкерское (военное) училище (1874–1918)
- Пехотные курсы командиров РККА (1920–1933)
- Топографический отряд (1934 г. – н.в.)

## Стек

- **PHP** 8.2, **Laravel** 11
- **Blade** — шаблонизатор
- **SQLite** (dev) / **MySQL** (prod, БД `museum_db`)
- **CSS** — единый файл `server/public/css/style.css` (BEM, CSS Custom Properties, 3 breakpoints: 1024px, 768px, 500px)
- **JS** — `server/public/js/main.js` (vanilla JS, без фреймворков)
- **Vite** — настроен, но не используется (ассеты отдаются из `public/` через `asset()`)

## Архитектура

Статический информационный сайт. Контроллеров нет — все роуты определены как замыкания в `routes/web.php`, каждый возвращает Blade-view. Модели предметной области не используются. Весь контент (новости, экспозиции, экскурсии, исторические статьи) захардкожен в Blade-шаблонах.

## Запуск

```bash
cd server

# Установка зависимостей
composer install

# Настройка окружения
cp .env.example .env
php artisan key:generate

# Миграции
php artisan migrate

# Dev-сервер
php artisan serve
```

Сайт будет доступен по адресу `http://localhost:8000`.

## Анализ конкурентов

Файл [`competitor-analysis.md`](competitor-analysis.md) содержит подробный конкурентный анализ:

- **Топ музеев Иркутска** (7 сайтов): Тальцы, Художественный музей Сукачёва, Музей декабристов, Краеведческий музей и др.
- **Топ музеев РФ** (10 сайтов): Эрмитаж, Третьяковка, ГИМ, Музей Победы, военно-исторические музеи и др.
- **Сводная таблица** функционала (25+ параметров) с оценкой каждого конкурента
- **Рекомендации** — что добавить на сайт, разбитые по приоритетам (критический / высокий / средний / низкий) с обоснованием каждого пункта

### Ключевые выводы из анализа

Военно-исторические музеи РФ имеют слабые сайты. Основные пробелы нашего сайта относительно конкурентов:

**Критический приоритет:** реальные фотографии вместо плейсхолдеров, реальные контактные данные.

**Высокий приоритет:** онлайн-билеты, версия для слабовидящих, соцсети, форма обратной связи, SEO meta-теги, фотогалереи, виджет Госуслуг.

**Средний приоритет:** виртуальный тур, календарь мероприятий, онлайн-каталог экспонатов, образовательный раздел, аудиогид (izi.travel).

## Известные проблемы

- Контент захардкожен в Blade-шаблонах (нет CMS/админки, нет моделей)
- Плейсхолдеры изображений вместо реальных фото на страницах экспозиции, архива, новостей, экскурсий
- Контактные данные-заглушки: `+7 (3952) XX-XX-XX`, `museum@example.ru`
- Расхождение адресов: в модалке «ул. Советская, 176», на странице контактов «ул. Ярослава Гашека, 5»
- `APP_NAME=Laravel` и `APP_LOCALE=en` в `.env` не обновлены
- Vite настроен, но не используется
- `server.zip` (33 МБ) — бинарный артефакт в корне репозитория
